# Beobachtung
### [[Beobachtung-Merkmale.jpg|Merkmale der Beobachtung]]
1. **Eine Beobachtung ist eine gezielte Wahrnehmung**
2. **Eine Beobachtung ist eine geplante Wahrnehmung**
Festlegung von Verhaltensweisen, Situation und Zeit
3. **Eine Beobachtung soll objektiv sein**
Wenig bis keine adjektive -> objektive Wahrnehmung - keine Wertung
Gleiche Bedingung = Gleiches Ergebnis
Auf das Beobachtbare zurückzuführen -> Operationalisierung
4. **Die Ergebnisse werden registriert**
- Ergebnisse der systematischen Beobachtung werden protokoliert
- Wertfrei, beschreibende Sprache
- Keine interpretation
- zuvor festgelegte Kriterien abarbeiten
- Technische mittel können zum Einsatz kommen (Ton/Video)
5. **Der Beobachtungsgegenstand wird so wenig wie möglich beeinflusst**
Nur zu schauen -> Nicht Eingreifen

### Alltagsbeobachtung

	- Gefühl von "Schon wieder das gleiche"
