Wenn das Ich zu schwach ist kann das Gehirn Abwehrmechanismen aufbauen. Diese entstehen durch Nichtbefriedigung von Grundbedürfnisse. 
Wenig Bedürfnisserfüllung = mehr Angst -> Abwehrmechanismus

# Projektion
Übertragung von Angst auslösenden Impulsen auf andere Gegenstände, Menschen.
**Bsp**: "Man bekommt eine schlechte Note und schiebt dies auf den viel zu schweren Test"

# Verleugnung
Gefahr wird vermildert dargestellt oder verleugnet
**Bsp**: "Das ist garnicht so gefährlich"

# Regression
Eine Entwicklungsstufe zurück fallen um an Aufmerksamkeit zu kommen.
**Bsp**: "Bettnässen nachdem ein Geschwister geboren wurde"

# Somatisierung
Psychische Beschwerden werden in Körperliche umgewandelt.
**Bsp**: "Bauchschmerzen vor einer Klausur"

# Autoaggression
Umlenkung von aggressiven Impulsen von fremdpersonen auf sich selbst.
**Bsp**: "Selbstverletzung bei mobbing"
